# Exemplo Loja Online

> Projeto criado durante o curso de técnico em informática durante o ensino médio.

## 💻 Sobre o Projeto

Este é um sistema de E-commerce (Loja Online) construído para fins acadêmicos e de aprendizado. O projeto engloba o lado do cliente com navegação de produtos, sistema de carrinho de compras, cálculo de frete, além de recursos para cadastro e login de usuários.

## 🛠 Tecnologias Utilizadas

- **PHP**: Linguagem principal utilizada para o back-end da aplicação.
- **HTML / CSS / JavaScript**: Estruturação, estilização e interatividade no front-end.
- **Python**: Scripts auxiliares (como `import_db.py`, `alter_db.py` e `update_users.py`) criados para facilitar manipulações e manutenção do banco de dados.
- **Banco de Dados (MySQL/MariaDB)**: Gerenciamento dos dados de usuários, produtos, categorias e vendas.

## 📂 Estrutura do Projeto

- `htdocs/loja/`: Contém todo o código-fonte da aplicação web (arquivos `.php`, folhas de estilo `.css`, e scripts `.js`).
- `htdocs/BD/`: Arquivos relacionados à estrutura do banco de dados.
- `htdocs/loja/admin/`: Área reservada para administração e controle interno (quando aplicável).
- **Scripts Python**: Pequenas automações criadas para a gestão do banco.

## 🚀 Como Executar

1. Instale um servidor web local com suporte a PHP e MySQL (ex: **XAMPP** ou **WampServer**).
2. Clone este repositório e mova a pasta do projeto para o diretório de execução do servidor.
3. Importe o banco de dados necessário (verifique a pasta `BD` ou utilize os scripts Python fornecidos).
4. Configure as credenciais de acesso ao banco de dados no arquivo `htdocs/loja/conexao.php`.
5. Acesse o projeto através do seu navegador em `http://localhost/Exemplo_LojaOnline/htdocs/loja/` (ou pelo caminho correspondente à sua instalação).
